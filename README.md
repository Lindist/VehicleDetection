# ระบบตรวจจับรถจอดในที่ห้ามจอดเฉพาะรถพยาบาลฉุกเฉิน (Ambulance vs Normal Vehicle No-Parking Alert System)

ระบบตรวจจับยานพาหนะอัจฉริยะด้วย AI YOLO ตรวจจับและแยกแยะ **รถพยาบาลฉุกเฉิน (Ambulance)** ออกจาก **รถทั่วไป** ในพื้นที่ห้ามจอด (No-Parking Zone) หากพบรถทั่วไปจอดแช่เกินเวลาที่กำหนด ระบบจะส่งเสียงแจ้งเตือนผ่านลำโพงทันที ออกแบบมาให้ทำงานบน **Raspberry Pi 4** หรือคอมพิวเตอร์ทั่วไป

---

## 📁 โครงสร้างโปรเจกต์

```text
Evaluation_of_a_Vehicle_Parking_Violation_Detection_and_Reporting_System/
│
├── config.yaml            # ตั้งค่าระบบ (เวลาผ่อนผัน, พิกัดพื้นที่, ลำโพง, แหล่งภาพ)
├── main.py                # โปรแกรมหลัก (กล้อง + YOLO + ตรวจจับจอดแช่ + สั่งลำโพง)
├── zone_setup.py          # เครื่องมือคลิกวาดพื้นที่ห้ามจอด (ROI) บนภาพจริง
├── tracker.py             # ลอจิกติดตามตำแหน่งและจับเวลาการจอดนิ่ง (Dwell Timer)
├── audio_player.py        # เล่นเสียงแจ้งเตือนแบบ Background ไม่หน่วงกล้อง
├── create_alert_sound.py  # เครื่องมือสร้างไฟล์เสียงแจ้งเตือนภาษาไทย
├── requirements.txt       # รายชื่อไลบรารีที่จำเป็น
├── assets/                # โฟลเดอร์เก็บไฟล์เสียง (alert.mp3 / alert.wav)
└── models/                # โฟลเดอร์สำหรับวางไฟล์ best.pt
```

---

## 🛠️ ขั้นตอนการติดตั้ง (Setup Guide)

### 1. ติดตั้งไลบรารีที่จำเป็น

```bash
# 1. สร้างและเปิดใช้งาน venv
python3 -m venv venv
source venv/bin/activate

# 2. ติดตั้งไลบรารีทั้งหมด
pip install --upgrade pip
pip install -r requirements.txt
```

*(หมายเหตุ: บน Raspberry Pi 4 หากต้องการติดตั้งไลบรารีเสียงเพิ่มเติม สามารถสั่ง `sudo apt-get install python3-pygame libsdl2-mixer-2.0-0`)*

---

### 2. นำไฟล์โมเดล AI มาวาง

1. นำไฟล์ **`best.pt`** ที่คุณเทรนเสร็จแล้ว
2. สร้างโฟลเดอร์ชื่อ `models` (ถ้ายังไม่มี)
3. วางไฟล์ไว้ที่: `models/best.pt`

> *หากยังไม่มีไฟล์ `best.pt` ในโฟลเดอร์ ระบบจะดึงโมเดลมาตรฐาน `yolov8n.pt` มาใช้ทดสอบระบบกล้องและเสียงได้ก่อนชั่วคราว*

---

### 3. สร้างหรือเตรียมไฟล์เสียงเตือน

รันคำสั่งเพื่อสร้างไฟล์เสียงแจ้งเตือนภาษาไทยอัตโนมัติ:

```bash
python create_alert_sound.py
```
*(จะได้ไฟล์เสียง `assets/alert.mp3` หรือเสียงไซเรน `assets/alert.wav` โดยอัตโนมัติ)*

---

### 4. กำหนดพื้นที่ห้ามจอด (Zone Calibration)

รันเครื่องมือช่วยกำหนดพื้นที่ด้วยการคลิกเมาส์:

```bash
python zone_setup.py
```

- **คลิกซ้าย**: วางจุดกำหนดขอบเขตพื้นที่ห้ามจอด
- **คลิกขวา**: ลบจุดล่าสุด
- **กด `s`**: บันทึกพิกัดลง `config.yaml` อัตโนมัติ
- **กด `r`**: รีเซ็ตล้างจุดทั้งหมด
- **กด `q`**: ปิดโปรแกรม

---

### 5. เริ่มต้นรันระบบตรวจจับ (Run System)

```bash
python main.py
```

**ปุ่มควบคุมและการตั้งค่าขณะรัน**:
- **ปุ่ม `[ SET ZONE (Z) ]` บนหน้าจอ**: ใช้เมาส์คลิกที่ปุ่มสีส้มมุมบนขวา เพื่อเข้าสู่โหมดตั้งค่าจุดพื้นที่ห้ามจอดใหม่ทันที
- **กดปุ่ม `z` บนคีย์บอร์ด**: เปิดโหมดตั้งค่าจุดพื้นที่ห้ามจอดใหม่ (ไม่ต้องปิดโปรแกรม)
  - *คลิกซ้ายวางจุดใหม่ $\rightarrow$ กด `s` บันทึกและนำไปใช้ตรวจจับต่อทันที*
- **กดปุ่ม `t`**: ทดสอบเสียงลำโพง (Manual Test Alarm Sound)
- **กดปุ่ม `q`**: ออกจากโปรแกรม

## ⚙️ การตั้งค่าใน `config.yaml`

| ตัวแปร | ความหมาย | ค่าเริ่มต้น |
| :--- | :--- | :---: |
| `camera.source` | แหล่งวิดีโอ (`0` สำหรับกล้อง, หรือใส่ชื่อไฟล์ `"assets/test.mp4"`) | `0` |
| `camera.process_fps` | อัตราประมวลผล AI ต่อวินาที (3-5 FPS ช่วยให้ Pi 4 ไม่ร้อน) | `3` |
| `parking.grace_period_seconds` | เวลาที่ยอมให้จอดได้ชั่วคราว (วินาที) ก่อนเริ่มส่งเสียงเตือน | `15` |
| `parking.alert_interval_seconds` | ส่งเสียงเตือนซ้ำทุกๆ กี่วินาที หากรถยังคงจอดแช่อยู่ | `8` |
| `audio.volume` | ระดับความดังของลำโพง (0.0 ถึง 1.0) | `1.0` |

---

## 💡 คำแนะนำสำหรับการใช้งานบน Raspberry Pi 4

1. **ลำโพง**: สามารถต่อลำโพงผ่านช่อง **3.5mm Audio Jack** หรือ **USB Speaker** ก็ได้ หากต่อ 3.5mm อย่าลืมตั้งค่า Output Audio ให้เป็น Headphones/Jack ด้วยคำสั่ง `raspi-config`
2. **การเพิ่มความเร็ว 2-3 เท่าด้วย NCNN**:

python -c "from ultralytics import YOLO; YOLO('models/best.pt').export(format='ncnn')"
   แล้วเปลี่ยน `model.path: "models/best_ncnn_model"` ใน `config.yaml`
